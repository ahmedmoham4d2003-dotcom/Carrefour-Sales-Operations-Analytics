# Carrefour Sales & Operations Analytics Dashboard

## Project Overview

This project presents an end-to-end retail analytics solution developed using Python, SQL, and Power BI to analyze Carrefour sales and operational performance.

The project focuses on transforming raw retail transaction data into actionable business insights through data cleaning, SQL-based analysis, KPI reporting, and interactive dashboard development.

The dashboard provides insights into:

* Sales Performance
* Customer Behavior
* Product Performance
* Regional Analysis
* Payment Methods
* Return Analysis
* Operational Trends

---

## Business Objectives

* Monitor overall sales performance.
* Analyze customer purchasing behavior.
* Evaluate product and category performance.
* Identify top-performing regions and stores.
* Track return rates and operational efficiency.
* Analyze payment method preferences.
* Support data-driven business decision-making.

## Project Workflow

### Data Cleaning & Preparation (Python)

The raw dataset was cleaned and transformed using Python and Pandas.

Tasks included:

* Handling missing values
* Removing duplicates
* Correcting data types
* Standardizing formats
* Preparing the dataset for analysis

### Data Analysis & Reporting (SQL)

SQL was used to prepare analytical datasets and business reporting tables.

Analysis included:

* Monthly Sales Trends
* Product Performance Analysis
* Customer Demographics Analysis
* Regional Sales Analysis
* Payment Method Analysis
* Return Rate Analysis
* Peak Sales Hours Analysis

### Dashboard Development (Power BI)

Interactive dashboards were developed using Power BI and DAX measures to support business reporting and performance monitoring.
